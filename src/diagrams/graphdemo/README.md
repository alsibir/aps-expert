# АС «АЛЬФА»: графические модели

Канонические исходники: `src/diagrams/graphdemo/plantuml/`.
Подписи и пояснения: `catalog.json`.
Страница: `src/content/docs/wiki/portfolio/analytics/alpha-graphic-models.md`.
Готовые SVG, PDF и ZIP: `public/images/graphdemo/`.

Исходники публикуются копированием в `public/images/graphdemo/plantuml/`,
чтобы посетитель мог скачать редактируемую модель. Не редактировать эти копии:
повторная компиляция заменяет их из `src`.

## Повторная сборка

Необходимы Java, Graphviz, DejaVu Sans, npm-зависимости проекта и PlantUML
**1.2025.10**. Версия зафиксирована для воспроизводимости; файл JAR не хранится
в репозитории. Дистрибутив: Maven Central, координаты
`net.sourceforge.plantuml:plantuml:1.2025.10`.

```bash
PLANTUML_JAR=/absolute/path/plantuml-1.2025.10.jar npm run graphdemo:render
python3 scripts/package-graphdemo.py
npm run build
```

Для упаковки PDF необходим Python `reportlab` и системные шрифты
`/usr/share/fonts/truetype/dejavu/`. Скрипт использует `sharp` из npm-зависимостей,
создаёт временные PNG вне репозитория и удаляет их после упаковки.

Скомпилированные материалы отслеживаются Git. Обычная сборка сайта использует
их без Java и без внешнего сервиса рендеринга. После изменения исходника
пересобрать SVG, альбом и архив до публикации.

BPMN и макет отчёта используют режим PlantUML `@startdot`. BPMN содержит
собственные события, задачи, шлюз и дорожки; диаграмма деятельности UML
представлена отдельно. Макет интерфейса создан средствами Salt и не является
снимком работающего продукта. Макет отчёта — дополнительное предложение
с синтетическими значениями, не заявленная функция опубликованного ТЗ.
