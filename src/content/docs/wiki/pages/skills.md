## Инструменты и технологии

| Задача | Средства и технологии |
| --- | --- |
| Подготовка документов, таблиц и схем | Word, Excel, Visio, Markdown |
| Проверка API и описание интерфейсов | Postman, Swagger (OpenAPI) |
| Работа с данными и мониторингом | SQL — запросы и проверка данных; Prometheus — метрики и наблюдение за состоянием систем |
| Моделирование систем и процессов | UML, BPMN, PlantUML, Mermaid, draw.io, Figma |
| Базы знаний и управление задачами | Obsidian, Confluence, Jira, Битрикс24 |
| Управление версиями и совместная работа | Git, GitLab, GitHub |
| Подготовка и публикация сайта | Astro, HTML, CSS, Visual Studio Code |
| Рабочая среда и виртуализация | Linux Mint, Windows, VirtualBox |
| Работа с искусственным интеллектом | ChatGPT, DeepSeek, YandexGPT, ГигаЧат |

ИИ применяется для подготовки черновиков, структурирования материалов и автоматизации повторяемых операций. Результаты подлежат проверке; передача исходных данных определяется требованиями конфиденциальности проекта.

## Принцип работы

Технический документ — результат анализа и проверки. Автоматизация помогает выполнять повторяемые проверки; утверждение фактов, достаточности требований и применимости стандартов остаётся задачей специалиста.
