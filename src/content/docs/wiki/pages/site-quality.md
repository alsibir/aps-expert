Сайт АПС служит профессиональным портфолио и базой знаний. Реализация демонстрирует структурирование информации, проектирование статического сайта и применение автоматизированных проверок.

## Назначение и требования

| Требование | Способ реализации и проверки |
| --- | --- |
| Представление квалификации | Главная страница, профессиональный профиль, матрица компетенций |
| Доступ к материалам | Портфолио, публикации, навигация и поиск Starlight |
| Управление исходниками | Markdown, MDX, компоненты Astro, Git |
| Просмотр и скачивание | PDF-просмотрщик на основе PDF.js, отдельное подтверждение скачивания |
| Адаптивность | CSS, светлая и тёмная темы, проверка в браузере |
| Индексация | Канонические адреса, JSON-LD, карта сайта |
| Конфиденциальность | Отсутствие собственных форм сбора данных и счётчиков аналитики |

## Архитектура и публикация

Исходники содержатся в [репозитории GitHub](https://github.com/alsibir/aps-expert). Astro/Starlight формирует статические страницы; сценарий postbuild нормализует ссылки, создаёт карту сайта и подготавливает PDF-просмотрщик. GitHub Actions выполняет сборку, проверки и развёртывание GitHub Pages. Исходники Markdown и MDX являются первичным источником текста.

## Контроль качества

| Проверка | Средство |
| --- | --- |
| Сборка и наличие ресурсов | npm run build |
| Локальные ссылки и изображения | scripts/audit.py |
| Якорные ссылки | scripts/audit-anchors.py |
| Просмотр PDF | npm run test:pdf |
| SEO и структурированные данные | scripts/audit-seo.py |

Команда `npm run audit:all` выполняет сборку и перечисленные автоматизированные проверки. Отчёты формируются в каталоге audit. Проверки интерфейса, контрастности, навигации с клавиатуры, мобильного просмотра и производительности дополнительно выполняются в браузере. Наличие автоматизированных проверок не означает подтверждённого соответствия всем требованиям WCAG или фактического достижения целевых показателей производительности.
