# Перенос сайта на /aps-expert/

## Подготовленное состояние

- Исходный коммит: `39e256f5fdd79be55da113c40de2d6d79cde6b40`.
- Резервная ветка: `backup/before-aps-expert-2026-11-14`.
- Ветка переноса: `migration/aps-expert`.
- Основная ветка до переименования не изменяется.
- Новый адрес: https://alsibir.github.io/aps-expert/.
- Задание публикации выполняется только в репозитории `alsibir/aps-expert`.

## Последовательность переключения

1. Дождаться успешных проверок запроса на изменения.
2. Владелец переименовывает репозиторий через Settings → General → Repository name: `aps-expert` → Rename.
3. Исполнитель проверяет доступ по новому имени, объединяет подготовленные изменения и проверяет публикацию.
4. При необходимости Владелец выбирает Settings → Pages → Source → GitHub Actions.
5. После проверки нового сайта Владелец создаёт публичный репозиторий `alsibir-expert`, добавляя README для инициализации. При ограниченном доступе приложения GitHub необходимо разрешить доступ к новому репозиторию.
6. Исполнитель размещает подготовленный сайт совместимости в старом репозитории. После его размещения Владелец выбирает Settings → Pages → Deploy from a branch → main → /(root) → Save.
7. Проверяются старые адреса главной страницы, статьи, портфолио, PDF-просмотрщика и файлов.

## Сайт совместимости

После основной сборки выполнить `node scripts/prepare-legacy-site.mjs`.
Результат: `out/legacy-site/`; в GitHub Actions он сохраняется как артефакт `legacy-site`.
Для каждой HTML-страницы создаётся переход на новый адрес. JavaScript сохраняет параметры и якорь, а также обновляет вложенные адреса документов в параметрах PDF-просмотрщика. При отключённом JavaScript доступна явная ссылка.
Документы, архивы и изображения сохраняются по старым путям. Страница 404 выполняет переход с заменой префикса пути; исходный ответ при этом остаётся HTTP 404. Серверный HTTP 301 этим механизмом не реализуется.
Создание репозитория со старым именем отключает автоматическое перенаправление старого адреса Git-репозитория. Перед дальнейшей синхронизацией следует обновить `origin` во всех локальных копиях.

## Локальные копии

В каталоге каждой рабочей копии:

```bash
git remote set-url origin https://github.com/alsibir/aps-expert.git
git fetch origin
git status
```

После проверки отсутствия несохранённых изменений: `git pull --ff-only origin main`.
Переименование локальной папки необязательно. Запуск: `npm run dev -- --open /aps-expert/`.
При изменении локального имени папки проверить рабочие области редактора, команды запуска и профили синхронизации.

## Внешние сервисы

После проверки публикации обновить адреса в резюме, профилях, подписи почты, Метрике и кабинетах поисковых систем. Новая карта сайта: https://alsibir.github.io/aps-expert/sitemap.xml.

## Восстановление

До создания репозитория совместимости возможен возврат исходного имени и содержимого из резервной ветки. После повторного использования старого имени сначала необходимо освободить его; автоматическое восстановление перенаправлений GitHub не предполагается.
