# Значки инструментов

Все SVG имеют внешний размер 64 × 64; пропорции исходных viewBox сохранены. Источники загруженных знаков перечислены в sources.json: Simple Icons (CC0), Lobe Icons (MIT). Фирменные знаки принадлежат правообладателям; отображение не означает партнёрство.

SQL и BPMN представлены условными текстовыми значками технологий. Для PlantUML, Битрикс24 и ГигаЧат используются текстовые обозначения, а не воспроизведение официальных логотипов.
